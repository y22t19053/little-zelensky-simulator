# v0.3.0 第一回合视觉样板

直接用浏览器打开 `index.html`。无需服务器、构建工具或网络。

本目录完全独立于正式游戏：不加载正式引擎、不写 LocalStorage、不结算国家状态。交互仅包括选择决策、更新签发栏与展示“预览已签发”反馈。

## 数据来源

- 七项初始读数：`../js/events.js` 的 `LZS_META.initialStats`。
- 3 AP、战争开始日期与第一回合四项决策：同一文件的 `LZS_META` 和 `LZS_EVENTS[0]`。
- “当前无告警”：按 `../js/engine.js` 的 `getAlarms()` 对初始状态核算。
- 定性决策标签只概括现有固定效果，不添加随机性或新数值。

## 文件

- `index.html`：语义化预览页面。
- `style.css`：独立响应式视觉样式。
- `scene-invasion.svg`：原创政治漫画、档案拼贴与局势关系示意，不含实时前线或兵力声明。
- `preview.js`：仅处理选中与签发反馈。
- `DESIGN.md`：修订后的产品方案、线框、披露规范与玩法风险审查。
- `preview-smoke.cjs`：可选的本地 Edge/CDP 验证脚本；会写入本目录 `screenshots/` 和临时浏览器 profile。
- `screenshots/`：实际浏览器验证后生成的桌面与手机截图。

## 已执行验证

`node design-preview/preview-smoke.cjs`（从项目根目录运行）已通过 1280×800、1440×900、320×740、390×844 四种视口。检查了真实初始读数、首屏决策入口、七项状态展开、44px 主要交互目标、选中与签发反馈、无横向溢出、无外部请求、无控制台错误/警告，以及不写 LocalStorage。

这里只是视觉预览，不是正式游戏构建；未执行正式版本完整回归或真实手机测试。
