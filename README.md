# 小泽模拟器 · Little Zelensky Simulator

> **你能顶住几天？**

一款单人、总统视角的战争危机决策模拟网页游戏。背景取自 2022 年 2 月 24 日俄罗斯全面入侵乌克兰后的最初一周。玩家扮演乌克兰总统，在有限注意力、不完整情报和有限资源之间分配优先顺序。

**v0.3.0 正式试玩版**，一局约 5–10 分钟。纯 HTML / CSS / 原生 JavaScript，无后端、无数据库、无外部 API、无第三方运行时依赖，断网可玩。

> **重要：** 本作是历史情景模拟，不是纪实作品，也不是对真实人物的评分。全部数值均为模拟设计参数，不代表真实统计或真实历史因果。详见[历史与模拟参数免责声明](#历史与模拟参数免责声明)。

## 立即游玩

- **线上版：** <https://y22t19053.github.io/little-zelensky-simulator/>
- **本地版：** 双击项目根目录的 `index.html`，无需安装、构建或启动服务器。
- **可选静态服务器：** 在项目根目录运行 `python -m http.server 8000`，再打开 `http://localhost:8000`。

游戏不通过 `fetch` 读取本地数据，因此在 `file://` 下也能完整运行。字体、肖像、样式、事件和复盘正文均随项目提供；只有结局后的资料来源链接需要联网打开。

### 存档

- 每次签发决策、结束回合和切换阶段时自动保存到浏览器 `LocalStorage`，键名为 `lzs_save_v1`。
- 只有一个存档槽位；关闭页面后可从封面“继续上一局”。
- v0.3.0 继续使用版本 1 数据结构，可以读取 v0.1.0 / v0.2.0 存档，并按当前规则保持互斥命令，不会重复结算。
- 封面提供“清除存档”。隐私模式或禁用本地存储的浏览器可能无法保存。

## 一局怎么玩

1. **阅读当日情报。** 游玩时只展示“当时已知”和“当时无法确认”。后续历史与事后判断不会提前泄漏。
2. **分配 3 点总统注意力（AP）。** 每项决策标注 AP 成本；签发后立即扣除 AP 并结算即时效果。
3. **处理互斥命令。** 留在基辅与转移、机场处置路线、参加与拒绝谈判等不能同时执行。冲突项会锁定，并说明与哪道已签发命令冲突；尝试执行不会扣 AP。
4. **至少签发一项决策后结束回合。** 未用完的 AP 不结转。
5. **阅读夜间结算。** 战争压力自动推进并侵蚀国家状态；到期延迟效果、临界警报和实际压力构成会分别列出。
6. **进入下一日。** 共 7 个回合，从 2 月 24 日推进到 3 月 1—2 日。
7. **查看结局与独立历史复盘。** 复盘包含逐日时间线、玩家路线对照、历史反思和资料来源。

同一项决策在同一回合不能重复签发。已签发文件会盖章并进入决策日志。

## 核心系统

### 总统注意力 AP

每天 3 AP，不累积；决策成本为 1–2 AP。AP 是本作最重要的限制：不可能同时处理所有方向。互斥关系由逻辑引擎校验，不只是按钮置灰。

### 国家状态

七项状态均为 0–100，所有变化都会夹在上下限内。

| 状态 | 含义 | 崩溃线（模拟值） |
| --- | --- | --- |
| 政府连续性 | 中央命令能否被制定、传递并执行 | ≤ 25 |
| 军队组织度 | 部队能否保持指挥、协同与补给 | ≤ 15 |
| 基辅安全 | 首都作为政治与指挥中心的可维持程度 | ≤ 12 |
| 社会抵抗意志 | 社会是否愿意继续承担战争代价 | ≤ 20 |
| 国际支持 | 盟友提供政治、情报与物资支持的意愿 | ≤ 10 |
| 战略储备 | 燃料、弹药、医疗与财政缓冲 | ≤ 8 |
| 总统个人安全 | 总统本人及核心团队的人身安全 | ≤ 10 |

任一状态崩溃条件触发，游戏立即进入对应结局。危险警报通常早于崩溃线出现。

### 战争压力与延迟效果

- 起始压力为 12，每个事件有固定压力上升值；部分决策也会增减压力。
- 压力越高，每晚对基辅、军队、储备、社会、政府和总统安全的侵蚀越强。
- 压力达到 100 会触发“系统过载”。
- 延迟效果在指定回合的夜间结算中触发，并显示来源、到期时间和内容。
- 夜间压力摘要分别列出战场上升与延迟效果，满足“结算前 + 战场 + 延迟 = 结算后”。
- 最后一个事件没有延迟效果，因为该回合后直接判定结局；其取舍体现在即时效果和最终状态中。

### 11 种结局

结局综合七项状态、战争压力和本局决策链，不使用单一总分。

| 结局 | 类型 | 触发条件（模拟） |
| --- | --- | --- |
| 总统安全崩溃 | 即时失败 | 总统个人安全 ≤ 10 |
| 政府连续性崩溃 | 即时失败 | 政府连续性 ≤ 25 |
| 基辅陷落 | 即时失败 | 基辅安全 ≤ 12 |
| 军队失去组织 | 即时失败 | 军队组织度 ≤ 15 |
| 抵抗意志瓦解 | 即时失败 | 社会抵抗意志 ≤ 20 |
| 外交空间坍塌 | 即时失败 | 国际支持 ≤ 10 |
| 后勤链条断裂 | 即时失败 | 战略储备 ≤ 8 |
| 系统过载 | 即时失败 | 战争压力 ≥ 100 |
| 撑过了第一阶段 | 阶段存续 | 七项状态达到完整存续线，且压力 < 95 |
| 代价高昂的存续 | 阶段存续 | 未达到完整存续线，但严重受损系统少于两项 |
| 空壳式存续 | 阶段存续 | 至少两项系统同时跌破严重受损线 |

结局页展示最终状态、关键决策时间线、延迟后果链和判定依据，不评价真实人物能力。

## 视觉与手机适配

- 采用 **Indie Strategy Game × Political Editorial × Wartime Archive**：深灰、军绿、低饱和琥珀、硬边档案与编辑拼贴，不使用外链资源或军事科幻 HUD。
- `assets/visual/events/` 包含七张本地 SDXL 生成并统一后期的 1152×640 WebP 主视觉；`assets/events/` 的七张原创 SVG 保留为降级备用。`assets/visual/maps/` 提供抽象态势叠层，均为模拟示意，不补充未经证实的前线、兵力或路线。
- `assets/zelensky.svg` 与 `assets/putin.svg` 继续作为原创政治漫画肖像；封面另外提供“怎么玩”和“历史资料 / 免责声明”。
- 桌面以事件主体、状态侧栏、决策文件和固定签发栏构成；1280×800 与 1440×900 首屏显示至少两项决策的标题和摘要。
- 手机显示三项紧凑状态，并提供“全部七项”展开入口；第一项决策前置，320px 窄屏允许自然滚动。固定栏包含 `env(safe-area-inset-bottom)`。
- 状态风险样式只读取引擎 `getAlarms()`；签发前显示 AP、收益/代价和定性量级，签发后及夜间显示实际数值，复盘披露完整参数。
- 所有主要触控目标至少 44px；决策卡支持 Enter / Space，弹窗支持焦点约束、Escape 与焦点恢复；支持 `prefers-reduced-motion`。
- 实测 1280×800、1440×900 桌面，以及 320×700、360×800、390×844、430×932 手机浏览器设备模拟视口。

## 本地音乐与音效

- 封面与游戏命令栏均有“声音”入口；音乐、音效可分别开关并调整音量。默认两者关闭，不强制自动播放。
- 四段 32 秒原创主题音乐用于菜单、日间、夜间与结局；日夜切换采用平滑 crossfade。十类短音效用于选择、签发、拒绝、结算与警报。
- 设置单独保存在 `lzs_audio_v1`，不改变 `lzs_save_v1`；刷新后恢复设置，但仍须用户交互才加载或播放音频。
- 音频只在对应功能开启后懒加载，页面隐藏时暂停。所有 Ogg、WebP 与 SVG 均随项目提供，断网可用。
- 原始文件、生成脚本、许可边界、逐资产清单与包体报告见 [ASSET_PROVENANCE.md](ASSET_PROVENANCE.md)；双击 `production/listening-room.html` 可离线试听。

## 已知问题与限制

- 没有战术地图、实时战斗、部队编成、多人模式、外交关系网络或 AI 自由对话。
- 只有一个存档槽位，没有导出 / 导入存档或云同步。
- 没有难度选择；合理决策可以改善局部或争取时间，但不能神奇消除整体战争压力。
- 最后一个事件没有延迟效果，因为之后直接判定结局。
- 手机适配通过四种视口的浏览器设备模拟验证，未覆盖所有真实设备、浏览器和字体缩放组合。
- 音频由实际 Edge 网络加载、设置与主题切换自动验收，并提供本地试听页；当前模型没有完成人耳听感评审。默认关闭音频，浏览器的自动播放策略可能要求再次交互。
- 历史时间线经过压缩；复盘是面向游戏的简明资料，不是完整战史或系统学术综述。来源链接可更新或失效。
- 所有数值都是模拟设计参数，不应作为真实统计、军事能力或历史因果引用。
