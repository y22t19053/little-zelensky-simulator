# v1.3.0 美术方向（战争档案视觉重制）

目标不是把网页做漂亮，而是让页面看起来像**一个真实存在过的战时办公室**：桌上摊着地图，手边是刚刚送来的电报，墙上钉着时间线，所有东西都留着使用痕迹。

## 1. 定位

**2022 年乌克兰战争初期的总统战时办公室 × 独立历史策略游戏 × 新闻编辑部 × 战争档案馆。**

玩家每一屏应该能回答三个问题：我在看什么文件、它来自谁、我现在要做什么。

## 2. 视觉语法：五种文件，五种待遇

本版本最大的变化不是换色，而是**不再把所有东西都做成同一种卡片**。

| 文件类型 | 视觉处理 | 版面特征 |
| --- | --- | --- |
| 决策文件（`.doc-order`） | 正式行政文件 | 暖纸底、硬边、签发线、右上角编号与密级；标题衬线加粗；选项像待签条款 |
| 情报报告（`.doc-intel`） | 打印简报 | 冷灰底、等宽标注、左对齐；带「可信度」印章 |
| 动态战报（`.doc-brief`） | 新闻电讯 | 无边框、仅上下细线、日期栏在左；像剪报贴进来 |
| 事务电报（`.doc-wire`） | 电报纸条 | 等宽全大写发报头、齿孔边、发报时间与来源 |
| 历史档案（`.doc-archive`） | 归档材料 | 米色卡纸、装订孔、横格、页脚归档号 |

统一的是**纸张、油墨、印章**三件事；不统一的是版面结构。

## 3. 色彩系统

保留低饱和军绿与档案纸，但把颜色变成有语义的三组。

| `--desk-2` | `#232a20` | 抬起一层 |
| `--desk-line` | `#3a4235` | 分隔线 |
| `--desk-line-soft` | `#2c332a` | 弱分隔 |

## 4. 字体与排版

- 标题/日期/编号：`archive-serif`（Noto Serif SC Bold 子集，OFL），`font-display: swap`，预加载。
- 正文：系统无衬线栈（Windows 微软雅黑 / iOS 苹方 / Android Noto Sans）。
- 编号、代码、状态小字：等宽。

字阶（桌面 / 手机）：

| 层级 | 桌面 | 手机 | 用途 |
| --- | --- | --- | --- |
| 封面主标 | 72px | 40px | 一次只出现一次 |
| 页面标题 | 34px | 26px | 区块标题 |
| 文件标题 | 24px | 20px | 决策文件、故事线标题 |
| 正文 | 16.5px / 1.72 | 16px / 1.7 | 阅读主体 |
| 标注 | 12.5px | 12px | 来源、密级、日期 |
| 微标 | 11px | 11px | 等宽，字距 0.14em，全大写 |

中文正文行高不低于 1.7；`letter-spacing` 只在大写等宽标注上使用。

## 5. 材质

三层叠加，全部克制：

1. 房间层：`--room` + `wall-grain.webp`（`opacity .28`，`mix-blend-mode: overlay`）。
2. 纸层：`--paper` + `paper-fiber.webp`（`opacity .5`，`mix-blend-mode: multiply`），边缘不做圆角，用 1px 实线与极短阴影（`0 1px 0`）表现厚度。
3. 油墨层：文字用 `--ink`，标题可用 `text-shadow: 0 1px 0 rgba(255,255,255,.25)` 模拟压印。

禁止：满屏做旧滤镜、扫描噪点铺满、霓虹光、玻璃拟态、统一圆角、雷达 HUD 网格。

## 6. 布局系统

### 6.1 桌面（≥1101px）

三区结构，不再是一条纵向长列表：

```
┌──────────────────────────────────────────────────────────┐
│ 报头：日期 · 窗口 · 幕次 · AP（琥珀三联）        [图标栏] │
├──────────────┬──────────────────────────┬────────────────┤
│ 左栏 280px   │ 中栏 主文件流            │ 右栏 320px     │
│ 态势        │ ┌ 总统工作台 ──────────┐ │ 情报桌摘要     │
│ · 战略地图  │ │ 待办 / 空状态 / 结束 │ │ 命令与事务     │
│ · 方向压力  │ └──────────────────────┘ │ 机构负荷       │
│ · 时间线    │ ┌ 本窗口文件 ──────────┐ │ 日志           │
│ · 故事线    │ │ 决策文件 / 情报报告  │ │                │
│             │ │ 动态战报 / 电报       │ │                │
│             │ └──────────────────────┘ │                │
└──────────────┴──────────────────────────┴────────────────┘
```

- 左栏是「房间里的墙」：地图与时间线常驻，滚动时 `position: sticky`。
- 中栏是「桌面上摊开的文件」：工作台在最上，文件名副其实地分类型排版。
- 右栏是「抽屉」：情报桌、命令、机构、日志。

### 6.2 平板（721–1100px）

两栏：中栏 + 右栏折叠进抽屉；地图收进中栏顶部，可展开。

### 6.3 手机（≤720px）

单栏，顺序固定为：报头 → 工作台 → （折叠）地图 → 本窗口文件 → 局势动态 → 待签文件 → 底栏。

- 地图默认折叠成「展开战役地图」的按钮，点开朗读。
- 时间线折叠成最近 3 个节点 + 展开。
- 决策按钮整行、最小 48px。
- 不缩放桌面字号，正文 16px 起。

## 7. 地图

`assets/visual/v13/map-kyiv.svg` + `js/visual.js` 驱动。

- 以真实地理关系为骨架：基辅居中偏东南；伊尔平河自西北向南穿过伊尔平、布恰西侧；杰斯纳河在东侧；主要方向为北（切尔尼希夫/杰斯纳）、西北（戈斯托梅利—布恰—伊尔平）、东（布罗瓦雷）、南（瓦西里基夫）。
- 表现的是**已知方向压力**，不是前线：用带状幅度、节点填充与虚线箭头表达「这个方向吃紧」，不画可执行战术路线。
- 图例与角标固定写明：「战略示意 · 非精确军事地图」。
- 状态来源：`getCampaignStatus`、`frontStatus`、`state.stats`、已经历事件（`state.campaign`）。
- 手机端可单独放大（点击展开为全宽 + 更大字号）。

## 8. 时间线

`js/visual.js` 从 `state.timeline` + `state.choices` + `state.campaign.feed` 生成。

节点类型：历史基准 / 你的决定 / 动态事件 / 延迟后果 / 故事线分支 / 结局。
桌面为横向（13 窗口），手机为纵向。每条节点标日期与来源，不给「+3 稳定」这类假数据。

## 9. 因果链

结局页的因果链只写真实记录：`决定 → 执行机构 → 延迟后果 → 新事件 → 结局影响`。缺哪一段就不画哪一段，不用装饰箭头填空。

## 10. 八条故事线的视觉身份

| 故事线 | 主图形 | 纸张 | 强调色 | 版面 |
| --- | --- | --- | --- | --- |
| 跑道与空域 | 跑道端视 + 空域弧 | 冷灰 | 钢蓝 `#7d93a8` | 工程记录：编号、坐标栏、附录 |
| 命令从哪一层发出 | 行政层级树 | 暖纸 | 铜棕 `#a8895f` | 公文：抬头、编号、签批栏 |
| 登记、征用与管不过来 | 表格与队列 | 米黄 | 土黄 `#b79a5e` | 清单：行号、数量、备注 |
| 两份互相矛盾的报告 | 两份错位纸张 | 冷灰 | 铁灰 `#8b9088` | 对照：左/右两栏互相打脸 |
| 求援的电报与车队 | 电报齿孔 + 车队 | 米白 | 琥珀 `#c9a869` | 电文：发报头、正文、回执 |
| 手里还剩多少能动的 | 力量方块阵列 | 暖纸 | 橄榄 `#88946f` | 账目：可支配 / 已投入 |
| 出城的路 | 路线与站点 | 米白 | 天青 `#7f97a3` | 交通记录：路线、站点、状态 |
| 撤退的迹象 | 时序刻度 + 核验勾 | 冷灰 | 灰紫 `#8c8496` | 核验报告：信号、来源、结论 |

实现方式：每份文件/战报带 `data-line="line_x"`，CSS 用 `data-line` 切换 `--doc-paper`、`--doc-accent`、`--doc-mark`（角标 SVG 符号），并给 `.doc-mark` 使用 sprite 里的对应 `<symbol>`。不是八张图配八个名字。

## 11. 动效

- 只允许三种：纸落下（`translateY 6px → 0`，180ms）、印章盖章（`scale .94 → 1`，220ms）、工作台更新高亮（1.4s 淡出）。
- 全部包在 `@media (prefers-reduced-motion: no-preference)` 内，减少动态效果时一律静止。
- 不给任何动效绑定游戏推进，不因动画延迟信息。

## 12. 逐页改造清单

| 页面 | 改造 |
| --- | --- |
| 封面 | 重做报头、旗标色条、主视觉（桌面 + 地图 + 文件三层矢量拼贴）、入口分区（正式战役 / 继续 / 战役档案 / 决策推演室 / 历史回声） |
| 开局介绍 | 变成「值班说明」单页：日期、你要做什么、三层次内容说明 |
| 总统工作台 | 顶部态势条（地图缩略 + 三条关键读数）、待办按文件类型分栏 |
| 决策文件 | `.doc-order` 版式：编号、密级、签发线、选项作为待签条款 |
| 情报桌 | `.doc-intel` 版式，六类机构各一种抬头 |
| 命令与事务 | 电报纸条 `.doc-wire`，状态用印章而不是色块 |
| 办公室日报 | 归档卡 `.doc-archive`，装订孔与横格 |
| 战役时间线 | 新组件，见第 8 节 |
| 多周目档案柜 | 卡片改成「档袋」：脊标、抽次、起止日期、结局印章；对照页改成两份记录并排 |
| 决策推演室 | 档案柜抽屉视觉强化：拉手、铜牌编号、纸卡 |
| 历史回声 | 展览式：时间轴 + 四条卡纸 + 来源栏，独立于战役界面 |
| 结局复盘 | 视觉总结页：主标题、地图定格、故事线、关键决定、时间线、结局判定 |
| 纪念海报 | 沿用现有版式，把地图与新字体接进来 |
| 七日经典模式 | 保持单文件界面，只换纸张与字体，不加桌面三栏 |

## 13. 不做的事

- 不改任何机制、状态数值、判定与存档结构（schema 仍为 7）。
- 不引入写实生成图当作历史照片。
- 不把所有页面套成同一种圆角卡片。
- 不为动画延迟信息呈现。
- 不在没有许可的情况下打包商业字体。
